# Adversarial implementation audit

Reviewer stance: assume the experiment is wrong until each path is shown
correct. Every item the brief listed is below with what was checked, the
finding, and the disposition. Corrections are recorded, never applied silently;
historical result JSONs are regenerated by re-running, not hand-edited, and the
`git_commit` field on each makes the provenance explicit.

Date: 2026-08-29. Commits referenced are on `master`.

## Summary of changes made by this audit

| # | Finding | Severity | Fix |
| --- | --- | --- | --- |
| A1 | Composed round-trip `decode(c^-1(c(D(x)))) == x` was never verified — only `decode(D(x)) == x`. | medium (correctness assurance) | `baselines.verify_composed_roundtrip`; run in `run_codec_experiment`; `composed_roundtrip_ok` in every record and the ledger; `FAIL_COMPOSED_ROUNDTRIP` prefixes the verdict; `tests/test_independent_verify.py` + property tests cover it. |
| A2 | `composition_gap_bytes` takes `min` over *available* codecs on each side independently → an asymmetric comparison if e.g. `xz9` OOMs on one side only. | medium (fairness) | `composition_gap_matched_bytes/pct` over the intersection; `available_raw_codecs` / `available_composed_codecs` / `codec_sets_match` recorded per row; a reportable positive additionally requires `codec_sets_match` or that the matched gap also clears the threshold. Pre-registered primary metric unchanged. |
| A3 | `encode_bytes_best_gf2` did `except Exception: continue` — a discovery/verify bug in one width would be silently skipped. | medium | failures are counted and the last message is put in `Encoded.notes`; `strict=True` re-raises; `tests/test_properties.py` exercises `column_basis` directly. |
| A4 | `decode_gf2` ignored unknown `flags` bits. | low (robustness) | rejects `flags & ~0b11`. |
| A5 | `bitstream._mask` had two identical branches. | cosmetic | removed. |
| A6 | No second, shared-nothing decoder — an encoder+decoder shared bug could survive. | medium | `verification/independent_verify.py`: own bit reader, own parse, plain-Python XOR / int reconstruction, independent accounting re-derivation. Wired into pytest and `scripts/reproduce.py`. |
| A7 | Vectorised bit I/O and GF(2) `reconstruct` (matmul) were pinned only by 15 frozen cases. | low | `tests/test_properties.py`: 200+200 randomised bit-array trials vs the per-bit loop; 60 `reconstruct` trials vs a per-column XOR reference (bases up to width 130); `column_basis` vs planted ground truth. |

Nothing above changes a size, a baseline, a preset, the accounting rule, or the
pre-registered threshold. A1–A2 add *stricter* validity gates; they can only
turn a claimed positive into "not reportable", never the reverse.

## Component-by-component

### Codec implementation (`src/deductive/codecs/gf2_codec.py`, `tabular_codec.py`, `passthrough.py`)

- **Encoder/decoder symmetry.** GF(2): every field written in `encode_gf2_matrix`
  is read back in the same order in `decode_gf2` (magic, version, kind, n_rows,
  n_cols, n_payload, flags, orig_len, leftover_n, leftover, pivot_mask, coeffs,
  payload, crc). Verified by round-trip tests, the 15-case byte-frozen
  equivalence set, 4-kind independent verifier, and randomised property tests.
- **`original is None` path.** When `encode_gf2_matrix` is called without
  `original`, it reconstructs a byte-padded bit string and that padded string is
  the round-trip target (decode returns the padded bytes). *Every experiment
  path passes `original=data`* (`encode_bytes_gf2` always does); the `None` path
  is used only in a few unit tests, which compare against the padded string
  explicitly. Documented here as a latent trap, not a live one.
- **`never_worse` / `passthrough_size`.** Closed form `n + 18`; asserted equal to
  `len(encode_passthrough(bytes(n)).data)` for `n ∈ {0,1,17,255,4096,1048576}`.
  A candidate is kept only if strictly smaller than passthrough.
- **CRC.** `zlib.crc32` of the original is written (32 bits, counted under `crc`)
  and re-checked on decode; a mismatch raises. It is *not* required for
  reconstruction, but it is counted, so it makes the container **larger**, i.e.
  conservative for the deductive side. It is identical work on the passthrough
  side, so it is neutral for `G_abs`.
- **Tabular affine.** Used only on synthetic FD controls and legacy phases 1/3;
  **the natural-corpus campaign uses `encode_bytes_best_gf2` exclusively.**
  Integer reconstruction uses Python ints; the synthetic tables are constructed
  to stay in int64 range. Column-index and count fields are 16-bit (≤ 65535
  columns) — documented implicit limit.

### Bit accounting (`src/deductive/bitstream.py`)

- `AccountedWriter.finalize()` raises unless
  `8·len(bytes) == Σ category bits` and adds the 0–7 pad bits to `framing`.
  This is the load-bearing integrity check and it is unconditional.
- A mis-typed category name lands in `extra` and *still counts toward the
  total*, so the total-bits check cannot be fooled by a typo (only the
  per-category breakdown could be, and every category string in the codecs is a
  literal reviewed here).
- `write_bit_array` / `read_bit_array` (numpy fast paths) proven byte-identical
  to the per-bit loop over 400 randomised trials with random pre/post
  misalignment (A7).

### Metadata accounting

- Categories: `payload`, `relation`, `header`, `leftover`, `crc`, `framing`.
  `metadata_bits_total = relation + header + framing + crc + leftover` is in the
  ledger. On planted GF(2) 1 MiB it is ~4.5 kbit against ~4.19 Mbit payload; on
  passthrough it is `18·8` bits. No transmitted bit is outside a category
  (enforced by `finalize`).

### Passthrough behaviour

- `encode_passthrough`: `magic·version·kind·len64·crc32·payload`, all
  whole-byte, no bit padding. `n_relations = 0`, `recovered_bits = 0`.
  `decode` re-checks the CRC. Null controls confirm i.i.d. bits, shuffled
  planted codes, and 1-flip near-relations all land here with `|G_abs| ≤ 19` B.

### Relation discovery (`src/deductive/relations/gf2.py`, `integer_linear.py`)

- `column_basis`: Gaussian elimination over GF(2) on packed uint64 rows; the
  resulting basis is checked by `verify_basis` against the *original* matrix
  before it is returned — a discovery bug raises `RuntimeError`, it does not
  produce a wrong-but-plausible result.
- Property test: on random info blocks made full-rank, `column_basis` returns
  `rank == n_info`, `n_relations == n_parity`, and `free_indices` exactly the
  planted parity columns, over 40 random shapes; on tall thin random matrices it
  returns full rank.
- Integer affine: relations solved on a few rows, then verified on **every** row
  with exact Python integers; a near-relation with one violating row yields
  `n_relations = 0` (tested).

### Basis encoding

- Homogeneous: `pivot_mask[n_cols]` then, per free column in increasing index,
  `coefficients[rank]`. Affine: same, `coeff_width = rank + ones_is_pivot`, and
  the all-ones column is never transmitted (synthesised at decode). Coefficient
  matrix written row-major (`reshape(-1)` C-order), read back with the same
  shape. Pinned by the equivalence set and the independent verifier.

### Framing assumptions

- One 0–7 bit pad to the next byte boundary, counted as `framing`. Passthrough
  never needs it (all fields byte-multiples) → `framing = 0` there, so the
  passthrough baseline carries no framing advantage/disadvantage.

### Composition pipeline

- `D(x)` is produced, then each stock codec compresses it; `composed_best` is
  the min over available. Decode order is `c^-1` then `E^-1`; A1 now verifies
  this end-to-end. `results/**/*.json` records the composed size *and* the
  round-trip result for every codec.

### Compressor invocation (`src/deductive/baselines.py`)

- `gzip` with `mtime=0` (deterministic); `zlib.compress(d, 9)`;
  `bz2.compress(d, 9)`; `lzma.compress(d, FORMAT_XZ, preset=9)`;
  `zstandard.ZstdCompressor(level=19)`; `brotli.compress(d, quality=11)`.
  All deterministic; re-running changes only `*_seconds`. Versions
  (`zstandard 0.25.0`, `brotli 1.2.0`, stdlib for the rest, Python 3.13.6) are
  recorded in every record's `machine.package_versions` and in the ledger.
- A codec that raises (e.g. `xz9` `MemoryError`) is recorded `available=False`
  with the exception and excluded from `min`; see A2 for the fairness guard.
- `skip_slow` (xz9/brotli11 skipped for >8 MB) is **not** used by the
  natural-corpus runner — it would weaken the baseline. It exists only for the
  legacy phase-4 helper scripts and is recorded when used.

### Output measurement

- Every "size" is `len(bytes_object)` of a fully materialised artifact —
  container, or `codec(container)`, or `codec(raw)`. No estimated or
  bits-to-bytes-rounded figure is ever compared; `passthrough_size` is a closed
  form only used for the never-worse test and is asserted against the real
  encoder.

### Round-trip verification

- `decode(encode(x)) == x` asserted in `run_codec_experiment` (raises on
  failure, no smoothing), in unit tests, and now the composed round-trip (A1)
  and the independent verifier (A6).

### Hashing

- `hashlib.sha256`. Dataset bytes hashed in `run_codec_experiment`
  (`dataset_sha256`) and pinned in `results/corpus_manifest.json` on first
  sight; a changed hash aborts the run (`pin_or_verify`). The equivalence
  reference stores container and reconstruction SHA-256.

### Random seeds

- All synthetic data from `np.random.default_rng(seed)` with literal seeds in
  the runners. `corrupted_gf2_code` derives its flip RNG as
  `default_rng(seed*7919 + 1)` (documented). No unseeded randomness anywhere in
  the experiment path. Property tests use a fixed seed (`20260829`).

### Dataset acquisition & integrity

- `try_download_*` are best-effort, resumable (SDRBench), and integrity-checked
  (Content-Length + full tar iteration; a corrupt archive is renamed
  `.corrupt`). Downloads live under the gitignored `data/downloads/`. Each
  corpus is SHA-256-pinned in `corpus_manifest.json`.
- Known event: the first SDRBench `exaalt-copper` fetch truncated (343 MB, tar
  EOF error); detected, file deleted, function hardened; the campaign uses
  `exaalt-2869440` (62 MB, tar verified, 7 files).

### Corpus selection

- The list is fixed in `docs/preregistration.md` §5 (git-locked). Scientific and
  telemetry corpora were named before any `load_*` result was inspected.
  Deferred/excluded corpora are logged with reasons in `docs/protocol.md` §4.
  No corpus has been dropped for being unfavourable.

### Baseline versions

- Recorded per record and in the ledger (`package_versions`). `paq8l` /
  `paq8px v216` are pinned by the archive under `data/downloads/` (not in git);
  `cmix` / `nncp` not run — `docs/environment_constraints.md` §3.

### Statistical calculations

- `G_abs`, `G_pct`, matched variants, raw gap — all computed in `results.py`
  from stored sizes, never typed. `docs/statistics.md` sets out the unit of
  analysis (per-file cross-corpus variation; deterministic codecs → no
  repeated-run statistics) and what is and is not a legitimate CI.

### Timing measurements

- `time.perf_counter()` around encode, decode, and each codec. Timings are
  reported for context only and are explicitly **not** part of any claim;
  re-running the campaign changes only timings and timestamps (verified:
  control JSONs differ solely in `*_seconds`).

### Reproducibility scripts

- `scripts/reproduce.py` (pytest+equivalence → downloads → controls → natural →
  phases → `results/REPRODUCE.md`), `scripts/build_ledger.py`,
  `scripts/regen_tables.py`, `scripts/check_paper_numbers.py`. Hardware
  requirement stated: whole-file `--mode whole` needs ≥ 32 GiB RAM.

## Ways the experiment could still mislead — residual, disclosed

1. **Detector scope.** A negative is about axis-aligned fixed-width GF(2) +
   integer affine only. Non-axis-aligned exact structure is untested (the single
   follow-up named in `docs/preregistration.md` §7).
2. **Baseline ceiling.** cmix / nncp not run (hardware). The planted-GF(2)
   control shows paq8l/paq8px do not absorb the gap, which bounds — but does not
   eliminate — the "a stronger mixer would" objection. Wording is limited to
   "the strongest context-mixing compressors we could run".
3. **Whole-file sweep pending.** Until `--mode whole` completes on adequate
   hardware the natural-corpus result is INCONCLUSIVE by the pre-registration;
   dev-machine slices are labelled and quarantined in `results/natural_slice/`.
4. **`encode_bytes_best_gf2` tries 12 configs and keeps the min** — a
   multiple-comparisons surface. Bounded by the never-worse guard, the
   composition requirement, and the null controls (i.i.d. / shuffled → passthrough).
   `docs/statistics.md` quantifies the false-positive rate of the 12-way min on
   random inputs.
